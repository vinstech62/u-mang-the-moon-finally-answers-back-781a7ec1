# The Moon Finally Answers Back

One line, in the voice of the Moon replying at last to the wishes, howls and
late-night promises of everyone staring up at it.

## Run

```sh
python3 main.py
```

Writes exactly one line to `/output/entry.txt`.

## Entry

> Four billion years of wishes, howls, and 3 a.m. promises — and not one of
> you ever wished me a night off.

105 characters, one line, deterministic — the same bytes on every run.
